## 3. New API: The Two Named Predicates

- [x] 3.1 Add `isCanonicallyEquivalent(to:) -> Bool` to `TextRope` (`Sources/TextRope/TextRope.swift`), implemented as `content == other.content`. Standard-library only — no Foundation import, per ADR-013. DocC MUST route callers explicitly: use this for render-equality questions ("would these show the same glyphs?"); `==` answers byte fidelity.
