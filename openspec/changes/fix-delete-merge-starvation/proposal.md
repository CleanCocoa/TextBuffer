## Why

ADR-012's starvation predicate is **per adjacent leaf**: an undersized leaf is legal only when it is provably starved against *each* leaf adjacent to it — `openspec/specs/rope-core-types/spec.md`, "Undersized leaf is only permitted when provably starved". The delete-path merge checks one side and stops. `mergeUndersizedLeaves` (`Sources/TextRope/Node+Merge.swift:33-63`) combines an undersized leaf rightward via `combinedLeaf` → `Node.rebalancedChunks`; when that combination is boundary-starved, the minimal-shortfall split's undersized output is accepted against *that pair* — the merge never asks whether the **other-side** neighbor could conformingly absorb it. This is DEF-017 (DEFECTS.md, `open`), the delete-path analogue of DEF-001's fifth manifestation, which was fixed for insert-overflow and construction only (`redistributeStarvedEdge`, `Sources/TextRope/TextRope+Insert.swift:85-99`, commit `1e6a6aa`).

Deterministic repro (from stress seed `0xDEF007` with the extender alphabet, iteration 48; reproduced byte-identically on pre-`fix-grapheme-seam-repair` sources, so it is pre-existing): leaves `[…, 1074, 1024, 1034, …]`, a delete across the 1024|1034 seam leaves the pair at `[1023, 1027]`. Their 2050-byte combination is starved — a `U+1F389` (old-alphabet emoji, no extender involved) spans its `[1024, 1026]` legal window — and re-splits to the same `[1023, 1027]` fixed point. But the *left* neighbor's 2097-byte combination has `Character` boundaries throughout its `[1024, 1073]` window, so the test-side validator reports it exactly: "Leaf has 1023 UTF-8 bytes … redistribution with leaf (combined 2097 bytes) would conform" (`chunkSizeViolations`, `Tests/TextRopeTests/TreeInvariantValidation.swift:67-87`).

The defect blocks the deferred half of DEF-016's coverage: `fix-grapheme-seam-repair` task 5.1 had to revert the stress-alphabet extenders (`\u{301}`, `\u{200D}`, `\u{FE0F}`) because the reshuffled RNG stream walks all five pinned seeds into this class (zero seam violations — the seam repair holds; every failure is this chunk-size class). The archived change's trimmed `rope-stress-testing` delta carries a dated note deferring the extender mandate to this change; that note is superseded here.

## What Changes

- **Same-parent other-side consultation in the merge accumulator.** When `combinedLeaf` (`Node+Merge.swift`)'s `rebalancedChunks` output contains an undersized chunk on its left edge, the merge makes a **single** additional redistribution attempt with the previously emitted leaf (`merged.last`): if the combination is not boundary-starved per `Node.isBoundaryStarved` — the exact predicate the validator applies — the two are re-split through `rebalancedChunks`; if it is starved, the undersized leaf is accepted as before. The right-side output needs no new mechanism: an undersized returned chunk keeps driving the existing loop rightward, and the end-of-list branch already consults leftward. This mirrors the insert path's `redistributeStarvedEdge` (producer/validator agreement via the shared `isBoundaryStarved`, as in commit `1e6a6aa`).
- **Cross-parent adjacency is reached at the ancestor levels of the delete path.** The validator defines adjacency over the *flattened leaf sequence* of the whole tree — document order, regardless of parents — so a within-parent repair alone cannot honestly satisfy it. A new edge predicate (`absorbableStarvedEdge(between:and:)`, spine walks mirroring `graphemeSeam(between:)`) detects an adjacent-subtree pair whose facing edge leaves include an undersized one that the cross-seam combination could conformingly absorb. It is wired exactly like the seam predicate: an or-term in `deleteFromInner`'s merge gate (`TextRope+Delete.swift:90`) and a disjunct in `mergeUndersizedInnerNodes`' combine condition, so `combinedInner` brings the two subtrees' children under one node where the leaf-level consultation above repairs the pair. Every cross-parent leaf adjacency touched by a delete meets at an inner node on the deletion path, so this covers the validator's predicate completely (design D1/D3).
- **The no-retry discipline is preserved.** The new step is one additional redistribution attempt per starved emission, decided by the same predicate that justifies acceptance — not a retry loop. A leaf starved against *both* neighbors remains a fixed point accepted without re-attempting, exactly as today.
- **Stress-alphabet completion (the deferred DEF-016 half).** `stressCharset` gains the three lone grapheme extenders and the blocked-note comment is retired; the per-operation-validated seed (`0xDEF007`) runs over the extended alphabet. **Headline acceptance criterion: all five pinned seeds (per-op `0xDEF007` + sampled 0/42/12345/`UInt64.max`) go green with the extended alphabet.** This is also the honest red-first signal — on current main with the extended alphabet they are red with `chunkSizeViolations` of exactly this class and zero seam violations.
- **Red-first deterministic repros without the stress machinery**: a minimal three-leaf `[1074, 1024, 1034]` shape whose seam delete must leave `chunkSizeViolations` empty, plus a height-2 cross-parent variant of the same trio.
- The `rope-stress-testing` delta reinstates the extender mandate (the two scenarios trimmed out of `fix-grapheme-seam-repair`'s delta) and supersedes that delta's deferral note.

No public API changes. Every touched symbol is `internal` or `private`; content, counts, and all read results are unchanged — the fix only changes where leaf boundaries fall. Rides the 0.11.0 train per DEFECTS.md.

### Modified Capabilities
- `rope-delete`: the undersized-leaf merging requirement gains the per-adjacent-leaf obligation — after any merge combination, an undersized output is legal only when starved against **each** adjacent leaf in document order (cross-parent adjacencies included, reached at the deletion path's ancestor levels); the other-side consultation and the deterministic repro become scenarios, and the no-retry paragraph states that the single consultation is not a retry
- `rope-stress-testing`: the mixed-encoding alphabet requirement reinstates the lone-grapheme-extender mandate deferred by `fix-grapheme-seam-repair` (extenders as insert operands; adjacency-formed clusters validated per operation), superseding the trimmed delta's deferral note
- `rope-core-types`: the grapheme-first bounds requirement clarifies that "adjacent sibling leaf" in the starvation predicate means adjacency in the flattened document-order leaf sequence — whether or not the two leaves share a parent — matching what the validator has always checked
