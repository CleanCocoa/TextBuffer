- [ ] 1.3 Write a test that unequal-length ropes short-circuit correctly on the boundary cases the summary alone decides: same UTF-16 count but different UTF-8 count (`"é"` vs `"aa"` padded to equal UTF-16 length), and same byte counts but different `lines`

## 2. Insert: single-pass re-chunk on leaf overflow (DEF-011, insert half)

- [ ] 2.1 Write a red perf test in `Tests/TextRopeTests/TextRopeInsertTests.swift` — *optional, may be dropped if unstable on CI*. Insert 1 MiB and 4 MiB of ASCII at an offset inside a middle leaf of a multi-leaf rope, measure each with `ContinuousClock`, and assert the 4× input costs less than 8× the time (linear ≈4×, the current quadratic ≈16×). Guard against timer noise by skipping the assertion if the 1 MiB baseline measured under a few milliseconds. This is the only task expected to fail before 2.5
- [ ] 2.2 Write the structural characterization test (passes before *and* after 2.5 — it is the regression guard, not the red test): insert a string of several hundred KB into a leaf that is **not** the root, i.e. into a rope already large enough to have inner nodes, at an offset inside a middle leaf.
